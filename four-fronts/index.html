Four Fronts

A one-life arcade game built for a computer graphics course. Enemy soldiers march in along four stone paths, and the hero in the middle has to stab each one before it reaches him.

  • One per tile: only one enemy can stand on each tile number at a time, so you face three at most.
  • Fury meter: every knockout fills it. When it is full, swords fly out in every direction and the game speeds up.
  • Drawn in code: every shape, from the pixel-art meadow to the swords, is drawn with OpenGL primitives. There are no image files.

The original runs as a desktop program. This page is a line-by-line port of that code to the browser canvas, so the rules, timing and art match.
