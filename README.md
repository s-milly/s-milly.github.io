# s-milly.github.io

Personal site for Shawn Miller: computer science (AI/ML) student and student-athlete at PennWest Clarion University.

Live at **https://s-milly.github.io**

## Updating the site

- **Projects** load automatically from public GitHub repos. To pin, hide, or rewrite a project, edit `projects.js`.
- **Résumé**: add the PDF to `assets/` and set `resume` in `projects.js`.
- **Experience** entries live in `index.html` inside the `<section class="experience">` block, newest first.

Plain HTML, CSS and JavaScript. No build step.
